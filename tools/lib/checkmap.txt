# Which checks a change calls for, read by tools/test.sh (docs/notes/general/testing.md).
#   <path prefix>  <tier>  <check>
# prefix  matched against the changed files (git diff against origin/main, plus uncommitted
#         and untracked files) or, given, the [area] argument. "@rpc" matches a diff whose lines
#         add or remove RPC or replication code.
# tier    quick: one headless Godot, no map, seconds.  net: headless server + client (tier 2).
#         full: the windowed / two-client / load scripts (tier 3), only under `test.sh full`.
# check   "--flag [args]" runs `godot --headless --path . -- --flag [args]`; a tools/ path runs
#         that script; "@netsmoke" is the runner's own headless server + client.
#         quick-tier Godot checks run with --fixed-fps 60 (game time, docs/notes/general/fast-checks.md);
#         "@realtime --flag ..." keeps one in real time.
# Only list a check that ends by itself and prints a RESULT line or exits non-zero on failure.
# Give each check the lightest world it works on (Core/Systems): `--world flat` (TestWorld, no
# map), `--systems ui` (only what is named), `--world fixture` / `--chunks fixture:<course>`
# (tiles built in code). Never the real map in quick/net.
