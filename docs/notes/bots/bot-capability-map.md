# Bot capability map: everything a player can do, use or meet, and whether a bot can

This is the living table that `general/new-feature-bots` asks every feature to update, as
`xr/vr-action-map` is for VR. One row per action, item, mount, vehicle or interactable.

The columns:
- **Seam**: how a body is driven without keys.
- **Server path**: the server method a bot calls (bots have no client).
- **Sense**: how a bot learns of it (`BotSenses`: sight with a ray, hearing, memory; `brain`).
- **Skill**: what a brain chains.
- **Status**: **ok** works for a bot today, **gap** not yet (the target is named), **n/a** not a bot's
  business.

Phases are those of #837: 2 = `BrBrain` on foot, 3 = vehicles, 4 = squads.
