# `Ui/FollowCam`: the spectator camera (#1268)

Taken out of the Battle Royale's client: a `Camera3D` that eases in 6 m behind and 2.8 m above the body followed,
added as a chunk anchor while active; ← / → (`ui_left` / `ui_right`, the D-pad, `XrPad`) step through the candidates.
The owner hands it the followable peers with `SetCandidates` when its state changes (BR: the living, team-mates first;
Versteckis: the hiders, then the seeker) and calls `Follow(delta)` each frame while spectating; `Prefer(peer)` (the
killer) and `Stop()`. The body is looked up only when the target changes: no LINQ, list or string per frame.
