# First-run welcome (#1131, `Ui/WelcomeScreen`)

## When it shows

- Once, over the title screen, on the first launch of a fresh install.
- `GameSettings.FirstRunDone` is **true by default**, so a settings file written before the welcome existed never
  shows it.
- `GameSettings.Load` sets it false only when there is no `settings.json` yet.
- The welcome saves `false` as it opens, so quitting half-way shows it again next time.
- **Never on a command-line run.** `Wanted()` needs no user arguments at all, so checks and tools always get the
  plain title.
  - `--welcome` forces it.
  - `--welcomecheck` forces it and saves nothing.
- Settings › Gameplay › Welcome › **Show again** pushes it over Settings.

## Pages

Every page can be skipped (**Skip the welcome**), and everything on it can be changed later.

1. **Name**
   - The Multiplayer name rules: 2 to 20 characters, `PlayerRegistry.Sanitize` (letters, digits, `-`, `_`).
   - A name that breaks them stops **Next** with the reason.
   - An empty name keeps "no name yet": Multiplayer still asks before joining.
   - Enter goes on.
2. **Figure**: `CharacterPage.Fill`, the Character menu's page (#1127).
3. **Account**: `AccountPage.Fill` (#1123). Offline is the default; online signs in or creates an account.

## Controls

- **Back / Next** (the last page says **Start playing**), with a step counter in the header.
- **Esc, pad B or the back arrow** go a page back. From the first page they close it as done.
- A pad drives it with A and the stick, like every page. VR uses the pointer.

## Saving

- The pages save one key each with `GameSettings.SaveOnly`, never the whole file, so no command-line override
  becomes a saved choice.
- `WelcomeScreen.Save` is the seam: `--welcomecheck` records into `WelcomeCheck.Record` instead.

## Check

`--welcomecheck` (quick tier):
- the welcome opens on page 1 and saves itself as not done;
- `a b` is refused with a reason, and `Heidi_92` is kept;
- it moves on to the figure, then the account;
- Esc goes back a page;
- **Start playing** returns to the title as done.
