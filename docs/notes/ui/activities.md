# Activities screen: launch, configure and join beside the console (#840)

- **What**: `Ui/ActivitiesScreen` (+ `.Br.cs`, `.Race.cs`), a `Screen` on the shell's stack (it holds the
  pointer and the movement keys like the pause menu, the world dimmed behind). Tabs **Invites**,
  **Battle Royale**, **Race**; LB / RB and Q / E step through them. Opened from the quick menu
  (Activities, Invites), the pause menu (`Activities`, online only), the wrist menu, and
  `ActivitiesScreen.Open(tab)`.
- **One server path**: every button sends the command the console takes, through `ChatManager.Send`
  (`/br open zug 6 normal duos`, `/race start 2000 car`, `/tpa Lea`), so the server checks everything
  again and the chat keeps working as before. The reply (private and error lines) shows in the status
  line at the bottom.
- **Refresh**: once a second (timers), and at once on `BrManager.StateChanged`, `InviteService.Changed`,
  `Parties.Changed` and `RaceManager.RowsChanged`. Lists are rebuilt only when what they show changes
  (a shape string), so a typed team name or town is never eaten; the seconds left are set in place.
- **Invites tab**: what waits for you (Accept / Decline), what you sent (Withdraw), "Ask someone" with a
  player picker (`RequestPlayerNames`): teleport to them (`/tpa`), ask them over (`/tphere`), invite to
  the party, challenge to a fist fight; the party with Put out (leader) and Leave.
- **Battle Royale tab** (state from `BrManager.Instance.State`):
  - Left: phase, area, size, team mode, joined, bots, countdown; the players (with team or party);
    the leaderboard in the lobby; Join / Leave, a team name, Invite to the lobby (`/br invite`).
  - Right, admin, idle: area (random, where I stand, a town with live suggestions from
    `ChatManager.PlaceSearch`), size (auto, 5, 6, 7 km), length, teams, bots (off .. 64) and their skill;
    **Open the lobby** sends `/br bots ...` then `/br open ...`. Lobby: Start in 10 s, the bots, Cancel
    (confirmed). Playing: Close the zone now, Cancel. The settings are kept for the session (`BrPick`).
  - Right, not an admin: how a match works. Opening one stays an admin's (`/br open`).
  - `BrState.BotLevel` (new, #840) carries the bots' skill to the screen.
- **Race tab**: the races on the server (`RaceManager.RequestRows` once a second while shown, answered to
  the asker: id, host, what, km, entrants, seconds to join, running / mine / joinable) with Join / Leave;
  start a road race (distance, mount, NPC racers) or an air race (a town or 3 km ahead, the aircraft),
  duel a player or an NPC with the same settings.
- **Screenshots**: `SHOTS=1 tools/invitecheck.sh` writes `test_output/invite_activities_{br,invites,race}.png`.
