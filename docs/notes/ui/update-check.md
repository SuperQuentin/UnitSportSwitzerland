# Update check (`Ui/UpdatePrompt`, `Core/UpdateInfo`, #532, #845)

- Once per session the title screen reads GitHub's release list (`releases?per_page=100`, public API, no token, 10 s timeout). If the newest stable tag is newer than `config/version` (stamped by `tools/release.sh`), `UpdatePrompt.Available` holds it, `UpdatePrompt.Found` fires, and the title menu shows an amber **Update to vX.Y.Z** entry at the top (#845). No popup at launch. One press (`UpdateNow()`) does the rest with no question; the entry is disabled while it runs and comes back when the update stops (`Stopped`: failed, cancelled, or a full archive saved).
- **Update** (delta): when every release after this one carries a `.delta` for this platform (`UpdateInfo.DeltaChain`), they weigh under 60 % of the full archive, the build is exported (`OS.HasFeature("template")`: never the editor's folder) and the install folder is writable. The deltas download to `user://updates/`, are staged on a worker thread into `.update/` beside the install (every hash checked), then the swap script starts at once and the game quits; the script waits for it to exit, swaps the files in and restarts the game. Format, script, tools: `tools/delta-updates`.
- **Download** (full archive): otherwise, or when patching fails ("Update failed" offers it). This platform's asset into the OS Downloads folder as `<name>.part`, renamed when complete; "Show file" opens the file manager on it (macOS: the `xattr -cr` reminder). That "Download complete" modal stays: the player unpacks by hand. No asset for this OS: the entry opens the release page. Failure modals ("Update failed", "Download failed") stay.
- Never looks: development builds (no version), headless runs, phones, command-line runs that skip the title. A reply that lands while another page covers the title still shows the entry (the title subscribes to `Found` until it leaves the tree).
- Flags (whitelisted in `GameShell.UseTitle`): `--fakeversion 0.0.1` pretends to be an old build; `--updatefeed URL` reads another release list (a local `python -m http.server`); `--updateaccept` answers yes to the remaining modals (failure, "Download complete"). `--uishot test_output/update.png 8` captures the title with the entry.
- Input: a title `MenuButton` and `Modal` buttons, so keyboard, pad and VR pointer work like every menu; no new action.
- Tier 0: `UpdateInfoTests`, `DeltaUpdateTests`.
