# Join from the website: `unitsport://join/<host[:port]>` (#1220)

- **Page:** `tools/deploy/web/index.html` has a **Join** button beside Copy, in the status card and in the Connect
  steps. Its link is `unitsport://join/` + the shown address (`location.hostname`, `:port` when not 7777).
- **A browser cannot tell whether the scheme is installed.** When the page still has focus 2 s after the click (no
  "open UnitSport?" prompt, no game), a hint appears: download the game, start it once, press Join again.
- **Registration:** `JoinLink.Register` (`src/Core/JoinLink.cs`) at every launch of an exported desktop build, beside
  `GpxOpenWith.Register` (`gpx/open-with`), so the handler follows the executable when it moves or updates. A fresh
  download handles links only **after its first launch**.
  - **Windows:** `HKCU\Software\Classes\unitsport` (`URL Protocol`, icon, `"<exe>" "%1"`), no admin.
  - **Linux:** `~/.local/share/applications/unitsport-switzerland-join.desktop` (`x-scheme-handler/unitsport`,
    `%u`), made the default with `xdg-mime default`.
  - **macOS, Android, iOS:** not done (no URL types in Godot's macOS export; no intent filter yet). The hint shows.
- **Launch:** the link arrives as a bare argument (before any `--`). `JoinLink.FromArgs` → `GameShell.Join` from the
  title screen, the metered-connection prompt included, and `LastHost` is saved. A second click while the game runs
  starts a second game (no single-instance handoff, as for .gpx).
- **Strict parse** (`JoinLink.Parse`, unit tests `JoinLinkTests`): the link comes from any web page, so only a
  hostname, an IPv4 or a bracketed IPv6 and a port 1-65535 pass; a trailing `/`, query or fragment is dropped.
