# Connecting starts with a protocol check

- `Net/Handshake` at `World/Handshake` on the server and every client. On connect the client sends
  `Hello(Handshake.Protocol)` and does nothing else (no name, no terrain sync) until `Welcome`; the
  server spawns the peer's player and sends it the world's state (interiors, occasions, placed
  objects, the time) only on a matching `Hello` (`ServerWorld.OnPeerAccepted`).
- **Bump `Handshake.Protocol`** on any wire change an older peer would misread. 2 = positions in
  LV95 (#185).
- **Its three RPCs (`Hello`, `Refuse`, `Welcome`) must never change.** Godot numbers a node's RPCs
  by name, so adding one to a node renumbers the rest and two versions call each other's methods by
  mistake; this node is how two versions find out they differ. A wrong protocol gets `Refuse` with
  the reason.
- A client older than the check never says hello: after `WaitSeconds` (10 s) the server kicks it
  through `ChatManager.KickPeer` → `NotifyKicked`, which every version has, so `ChatManager`'s RPCs
  must not change either. A server older than the check never welcomes: the client leaves with a
  message after 10 s. Spawns other than the peer's own player (vehicles, radios) still reach an old
  client before it is kicked; it may log errors meanwhile.
- The status query carries it too (`ServerStatus.Wire`, 0 from older servers): the Multiplayer
  screen marks a server of another version in red ("other game version").
- Swarm bots (`--swarm`) shake hands like a client.
