# Adventure: flags and checks (#1223)

## Flags

- `--systems ...,adventure`: the Adventure layer on a narrowed run. Off on `--world fixture` and on a
  test world unless named (`Core/Systems`).
- `--adventure-test`: adds the checks' quests (`ProbeQuests`, 30 m from the default spawn) on a server
  or a client. Never for players.
- `--adventure-dir <dir>`: where progress is saved instead of `user://adventure` (a check's folder).
- `--journal`: opens the Journal on the Birds tab 1.5 s after boot (a screenshot).
