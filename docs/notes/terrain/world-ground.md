# The ground gameplay asks: `IWorldGround` (#1532, G2 C1)

- **One interface for every ground query of gameplay** (`src/Terrain/IWorldGround.cs`): `TryGetHeight`,
  `TryGetSurface`, `TryGetCover`, `TryGetWaterLevel`/`TryGetWater`, `InTunnel`, `InPit`, `FloorBelow`,
  `HasCollisionAt`, `BuildingCollisionDoneAt`, `TileAt`, `GroundAt` (a tile's ground mesh), the streaming
  anchors, `Origin`, and the tile events (`TileEntered`, `TileUnloaded`, `TileFurnished`,
  `TileUnfurnished`, `TerrainReplaced`). Positions are world-space; a tile is a `GroundTile`. No LV95 key
  or corner in it, so G2's leaf world serves it unchanged (C1's second half).

  not convert to an `IWorldGround`: whoever wires a world (`Terrain = chunks.Ground`) goes through the one
  property the earth world will point at its leaves. The queries themselves are private on `ChunkManager`
  (`HeightAt`, `WaterAt`, `CoverAt`, ...), the same code as before; `HeightAt` is `internal` for the
  streamer and `--worldgroundcheck`'s direct leg.

  things too (probes, `ClientWorld`) writes `_chunks.Ground.TryGetHeight(...)`; a possibly null streamer
