# Build features: what an exported build carries (#1074)

- **One switch, `UNITSPORT_FEATURES`**, read by `UnitSportSwitzerland.csproj`. It is an environment variable, because Godot's export runs `dotnet publish` itself and MSBuild reads the environment as properties.
  - **The editor (`Debug`) has every feature**, whatever the variable says. That covers `tools/test.sh`, every probe and `tools/trailer.sh`: they all run the editor build.
  - **An export (`ExportRelease`, `ExportDebug`) has none** unless the variable lists them, comma-separated, or `all`: `UNITSPORT_FEATURES=trailer tools/release.sh`. A plain release (CI, `release.sh`) carries none.
- **A feature is a define plus a `<Compile Remove>`**, like `PLAYTEST` (Debug only, no switch). Its call sites outside its folder are `#if <DEFINE>`.

| Feature | Define | Files | Call sites outside |
|---|---|---|---|
| `trailer`: the trailer studio (`src/Trailer`, #706) | `TRAILER` | 25 files, ~9.4k lines | the camera tool row in `ClientWorld`, `SubtitleCut` in `Main`, the film date in `Calendar.PinnedDate` |

- **Check a switch** without exporting: `UNITSPORT_FEATURES=trailer dotnet msbuild UnitSportSwitzerland.csproj -p:Configuration=ExportRelease -getProperty:DefineConstants` (and `-getItem:Compile`). Build the export configuration once after adding an `#if`: the editor build always has the define, so only `dotnet build -c ExportRelease` finds a call site left unguarded.
- **Not features, and kept in every build:**
  - Movie: the replay buffer, F5 clips, Pause → Save clip / Record / Movie studio are a player's tools. Its three probes go with the dev tools.
  - The debug menu (F9; online for admins only), the performance overlay and the perf recorder: players reach them through Settings.

  - **They cannot be picked by name.** `Avatar/MeshScratch.cs` is production code. `ModelViewer.Shaded` is called from `[Showcase]` builders in production files, and `TestWorld.TryGround` from `Player/Boat.cs`. Some self-checks are methods of production classes (`CarSetups.Check`, `Interest.SelfCheck`).
