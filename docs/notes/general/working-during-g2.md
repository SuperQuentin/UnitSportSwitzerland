# Working on other features while G2 runs (#1500)

G2 moves the game from flat LV95 tiles onto cube tiles in true Earth positions (`docs/plans/global-tiling-g2.md`).
Positions (A) and the build tools (B) are done; the game on the new tiles (C) and the flip that deletes the LV95
runtime (D) are not. Until D lands, the game still plays on LV95 tiles by default, and other features can go on
if they keep to these rules.

  (`net/positions-on-the-wire`). It carries over to the round world as is.

  reads. `FlatLv95RatchetTests` fails on any growth (`general/flat-lv95-ratchet`). LV95 stays only as notation:
  what a person types or reads.
- **No new store keyed by LV95 tiles or LV95 metres**: key by `CubeKey` or an Earth position. D re-keys the old
  ones (farm, loot, shop, chests, claims).
- **New data in the build tools** (TerrainPreprocessor, RoadGen) goes through the stage seams (`IFeatureSpace`,
  `IRoadSpace`, `IUnits`, `IGround`; `tools/cube-frames`) and works in both builds: the LV95 build stays
  byte-identical, the cube build is checked with `--cube-compare` and `--cube-check`.
- **Headings in data** stay grid north with the true-north view beside them (`TrueHeading`) until D.
