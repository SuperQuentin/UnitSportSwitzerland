# Every Godot launch steals focus on macOS

- **Every game launch brings Godot to the front on macOS**: the app activates while the engine
  starts, before any project code or setting is read. With Stage Manager or a fullscreen app it
  switches the person at the machine away from what they were doing. Tried, does not help:
  `display/window/size/no_focus` (via `override.cfg`), `open -g -n -a Godot_mono.app`.
- **`--headless` is no way out for pictures**: its dummy renderer draws nothing, so `--shot`
  has no frame to save.
- **Playing from the editor does it too**: `project_run` (godot-ai MCP) unhides a hidden editor
  and makes it frontmost for about a second, even though the game is embedded in its Game tab.
  A game already running embedded in a hidden editor keeps rendering (`editor_screenshot
  source="game"` gives live frames) without taking focus again.
- **So**: launch once and keep the process. For screenshots, `--shot-queue <file>` (`commands`)
  takes any number of shots from one launch. Ask before launching a window on someone's
  machine while they work.
