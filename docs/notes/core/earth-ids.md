# Earth ids for what is generated per leaf (#1514, G2 C5)

Decided with the user (comment on #1514, Nov 5 2026; the hookup Nov 8 2026): C5 lands the ids and the per-leaf
generators as tested code; **C1's PR 2 (furnishing leaves, #1510) calls them** when it furnishes a leaf behind
`--frame earth`. The saved stores, their migration and the farm/herd RPCs' protocol bump stay with D
(`core/saves-in-earth-positions`). Code: `tools/TerrainFormat/EarthIds.cs`; tests: `EarthIdsTests`.

- **`BuildingId`**: a building's footprint centre as latitude/longitude in 1e-5° units (1.1 × 0.76 m at 46°), text
  `b4620412_614871` (`_1`, `_2` for a duplicate solid in the same unit, numbered in tile index order by `Assign`).
  It replaces `BuildingKey(TileE, TileN, Index)` as the seed and save key on leaves: loot (`LootTables.ContentsOf` hashes
  the key text), shop, lock and gift rolls take it unchanged and reshuffle once. `BuildingKey.TryParse` refuses it.
  - The centre is the area-weighted centroid of the roof and floor triangles seen from above (walls skipped), in any
    frame the same point: `OnLeaf(leaf, building)` (anchor frame) and `OnLv95Tile(tile, building)` agree.
  - **Measured on B4's D: region** (the LV95 build and the leaf build, two Geneva bundles, 203 LV95 tiles): 28,165 of
    28,168 EGIDs get the same id from both builds; the 3 others are one unit apart (centres on a unit's edge). Compare
    by EGID as sets: an EGID can name several solids.
  - The text decodes back to a place (`LatDeg`, `LonDeg`): D's migration finds the building from an old save's id.
- **`EarthCells`**:
  - `SpotId(prefix, ecef)`: a reward spot's id on a leaf, its level-20 cube cell (~9.5 m), `ch:F0L20x123y456`, as
    LV95's `RewardRules.CellId` was its 10 m corner (`ch:2600150_1200340`, remapped at D). No `_`, so
    `RewardRules.TryTile` refuses it; `CellOf(id)` reads the cell back.
  - `LotteryCells(leaf)`: the lottery cells of a leaf, level 16 (~150 m, 16 to an L14 leaf), in (y, x) order;
    `Seed(cell, salt)` the rewards' FNV-1a over the cell; `Chance(p, Area(cell))` = p · area / 250², so a km² draws
    as often as on LV95's 250 m cells (one draw a cell).
- **Films** (`Trailer/FilmCoverage`): `LeavesNear(need, radius)` / `MissingLeaves(needs, real)` are the real-ground
  check on cube leaves, beside the LV95 km tiles; trailer `Spot`s stay LV95 notation (`WorldOrigin.ToWorld(e, n, alt)`
  goes through ECEF in a non-flat frame).
- **What C1 PR 2 wires** (none of it reachable before buildings and fields exist on leaves in the game):
  - a leaf's buildings keyed by `BuildingId.Assign(buildings, b => BuildingId.OnLeaf(leaf, b))` wherever the flat world
    uses `BuildingKey` text (interiors' layouts, loot, shop, locks, Christmas claims);
  - `RewardPlacer`'s cell lotteries over `EarthCells.LotteryCells(leaf)` with `Chance`, spot ids from `SpotId`;
