# Earth stores: `user://earth/`, by leaf and BuildingId (#1726, G2 D2)

Since D2 the game plays `--frame earth` by default; `--frame flat` is a hidden rollback (command line only, never
saved) until D3. Every store that was keyed by an LV95 tile or a flat building key lives **beside** its flat one, so a
rollback finds the flat files untouched and the next flip reads the earth ones again.

## Rules

- **Path**: `WorldChoice.StorePath("user://x")` = `user://earth/x` under earth, the flat path under flat, then mapped
  for a test world like `SavePath`. `EarthStores` (plain C#) holds the mapping.
- **One file per LV95 tile becomes one per leaf**: `LeafTileName.FileStem(tileId)` gives `F4_L14_X_Y` for a leaf's
  stand-in tile, `E_N` for an LV95 one (so the flat path keeps its names). `LeafTileName` is the plain half of
  `LeafStandIn` (its `Id`/`TryLeaf`), linked into the tests.
- **A building inside a store** is named by its Earth identity: `EarthStores.Building(key)` returns the `BuildingId`
  the stand-in key is aliased to (`Fnv.Alias`, registered when the leaf loads), the key itself otherwise.
- **Rings across face edges**: `LeafTileName.Rings`/`Around` walk `CubeKey.Neighbours` when two leaves are on different
  faces; LV95 tiles keep the lattice arithmetic.
