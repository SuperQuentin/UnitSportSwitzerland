# Delta updates (`tools/DeltaGen`, `tools/deltas.sh`, #532)

- Each release carries, per platform, `UnitSportSwitzerland-vA-to-vB-<windows|linux-x86_64|macos>.delta` from the previous release. The game chains them (vA -> vB -> vC) and falls back to the full archive when a link is missing (`ui/update-check`).
- Made from the **published** archives, so the delta matches exactly what players have: `tools/deltas.sh vA vB [--upload]` downloads (or takes vB from `test_output/release/`), unpacks, runs `DeltaGen make`, then proves each delta by `DeltaGen apply` on a copy of vA (the game's own staging and swap script) and `diff -r` against vB. `tools/release.sh` runs it with `--upload` after `gh release create`; a failure leaves the release standing and prints the retry line.
- Measured: v0.8.0 -> v0.8.1 is 8 KB (Windows), 24 KB (Linux), 15 KB (macOS) against 176-225 MB archives; v0.7.0 -> v0.8.0 (a code release) 2.2 MB. The Godot executable only changes by a few bytes between releases.
- Format (`Core/UpdatePackage`, Brotli): magic, from, to, entries `Add` (whole file), `Patch` (`Core/BinaryDelta`, rsync-style: rolling hash over 2 KB blocks, matches extended both ways, resumes on the last copy's diagonal, so shifted .pck content is found) or `Delete`, each with the SHA-256 of the file it expects and of the file it makes. A patch only when it is under 90 % of the file.
- Paths are refused unless they stay inside the install (`UpdatePackage.SafePath`: no rooted, drive, backslash, `..`, or `.update/`). macOS deltas are relative to the `.app` (the install root the game patches).
- Staging (`UpdatePackage.Staging`): new files to `.update/files/`, deletions to `.update/delete.txt`; a later delta reads what an earlier one staged; any hash mismatch (modified install, wrong delta) throws and the folder is dropped. On Linux/macOS a patched file keeps its mode; an added one gets exec when `--exec` listed it (`deltas.sh` lists the binary, `bin/*`, `Contents/MacOS/*`).
- Swap (`Core/UpdateScript`): Windows locks the running exe and .pck, so the files move after the game quits: PowerShell (`apply.ps1`, UTF-8 with BOM for 5.1) or sh (`apply.sh`) waits for the PID, moves the files with retries, deletes, removes `.update`, optionally relaunches; failure -> `update-error.txt` in the install.
- Checks: tier 0 `DeltaUpdateTests`; `DeltaGen apply [--sh]` (Git Bash's sh runs the Unix script on Windows); in-game end to end: export two builds stamped 0.0.1 / 0.0.2 (add `test_output/*` to the preset's exclude filter in a worktree), `DeltaGen make`, serve a `releases.json` with `python -m http.server`, run the old one with `--updatefeed http://127.0.0.1:PORT/releases.json --updateaccept`: it updates, quits, the script swaps and relaunches, and the folder equals the new export.
