# RoadGen behind `IUnits`, `IGround` and `ITileLoop` (G2 B3 4a, #1507)

The network stage (`TileRewriter`) keeps its maths; what it assumed of the LV95 grid comes through three
seams, each with an LV95 instance that writes the same bytes as before (plan `docs/plans/global-tiling-g2.md`,
B3 row 4a; the frame instances are 4b, the generated world's move to leaves B5).

- **`IUnits`** (`tools/RoadGen/Geometry/Units.cs`): the plane and its tiles. `TileAt(x, y)` (was
  `TileId.FromLv95`), `West`/`South`/`North` of a tile (was `MinE`/`MinN`/`MaxN`; tile-local x = plane x − West,
  z = North − plane y), `TileSizeM` (the km caches and the edge tests: `Facades`, `UrbanField`, `PaintEmitter`,
  `RailRoadOverlap`, turn-lane seams), `DirectionToTile` / `AngleToTile` (every heading written into a tile:
  signal poles, overheads, gantries, signs, tram stops, approaches, car-park fixtures and bays). Plane units are
  metres (LV95's grid metres by the LV95 build's convention; a frame's orthographic plane within 3 ppm), so no
  length is scaled. `Lv95Units` is `TileId`'s own arithmetic and the identity for directions.
- **`Plane`**: the instance a run is on, `[ThreadStatic]`, `Lv95Units` by default; `Plane.Use(units)` scopes it.
  `Session.Block` and `Run(ITileLoop)` set it from `Inputs.Units`, so the static planners (`CornerPlanner`,
  `StreetPlanner`, ...) need no new parameter. The stage is synchronous (no `await`, no `Parallel` in a block):
  keep it so, or pass the units explicitly. `Facades` binds its units at construction (a shared pair is built
  outside a block; `UrbanField` takes the facades').
- **`IGround`** (TerrainFormat's, `cube-frames`): `Inputs.Ground` (a block's ground over its tiles and halo) or,
  unset, `Lv95TileGround` over `Inputs.Grid`. `Lv95TileGround` reads only the tile `FromLv95` names, as the stage
  always did: TerrainFormat's `Lv95Ground` also tries the tiles west and south of a point on an edge, which would
  answer at the halo's outer edges where the stage had no height (other bytes).
- **`ITileLoop`** (`Rewrite/TileLoop.cs`): the blocks, the wanted tiles, the inputs, `Write(tile, bytes)` and
  `Finish()`. `Lv95TileLoop` is the old file-based `Run` (raw input or a fresh tile, the refusal of rewritten
  tiles, the OSM/canton/signal/gantry inputs, 6 km blocks, `.road` written through `.part`, the gantry facts);
  `TileRewriter.Run(chunkDir, ...)` builds it, `Run(ITileLoop, ...)` runs any loop. `Rewrite(block, ...)` (the
  generated world, `FallbackChunkSource.Roads`) is unchanged.
- **Left LV95 on purpose** (4b, lat/lon inputs): the canton lattice (`Cantons.CodeAt`, a km lattice of LV95 data),
  SITG's bearings (`BearingOf`), the OSM overlay and nodes, tram stops, places. Diagnostics (`--signal-check`,
  `--kerb-check`, `--street-svg`) and the synthetic test region stay LV95 tools.

# On work frames (G2 B3 4b, #1507, PR #1543)

The frame instance of the three seams, and `--cube-network`, which runs the stage over a cube region.

- **`FrameUnits`** (`Geometry/FrameUnits.cs`): the plane is a work frame's. Each level-14 leaf is a tile, named by
  a `TileId` (E = face × 2^14 + x, N = y), so the stage's dictionaries and caches stay as they are. Its tile-local
  frame is a **1000 m square on the plane, plane-aligned and centred on the leaf** (the centre snapped to 2 m, so the
  0.5 m and 2 m rasters line up across leaves; a leaf is ~610 m, turned). `OnEdge`/`Inside`/`OnAnyEdge` use the
  leaf's own edges through its `LeafTransform`; `Around` walks `CubeKey.Neighbours` (across face edges).
  `DirectionToTile`/`AngleToTile` are the identity: both instances' tiles are plane-aligned.
- **`LeafRecords`** (`Rewrite/LeafRecords.cs`): a tile's records between that square (y = height above sea level)
  and the leaf's anchor frame, every position by `PlaneToLocal`/`LocalToPlane`, every heading by the Jacobian
  (Godot headings, approach angles, gantry and overhead headings, bays). Arrays are changed in place (paint along a
  segment, transitions, junction paths and conflict pairs keep their references); init-only positions are set by
  reflection. Heights kept apart from a point (a structure's lower edge, a wire) go through the point.
- **`RegionData`** (`Rewrite/RegionData.cs`): the region's files read once (the LV95 loop uses it too); `On(...)`
  moves the OSM nodes, SITG gantries (bearings too), places and tram stops onto a frame's plane (LV95 → plane at the
  ground's height, rigorous), and asks the canton lattice through plane → LV95. The OSM overlay's distances along a
  line stay LV95 grid metres against the raw keys' true metres (within the plan's 2×10⁻⁴).
- **Seams added for frames**: `IUnits.OnEdge` (`PaintEmitter`'s dash phase now takes the tile), `Inside` (the turn
  pockets' and junction room tests), `OnAnyEdge` (`RailRoadOverlap`), `Around` (the halo, the footprints' scan).
