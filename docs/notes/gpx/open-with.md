# Open a .gpx with the game: its replay starts (#1029)

- **What:** a .gpx opened *with* UnitSport from outside goes straight into its replay (`GameShell.OpenGpx` → `GameMode.GpxReplay`). The file is copied into `user://gpx` first when it is an Android URI (`GpxPicker.Import`, `gpx/android-gpx-picker`), and added to the recent tracks. If a world is running it is left first; the replay follows behind the loading screen, like a rejoin.
- **Desktop:** the file is a bare launch argument (before any `--`). Godot takes a positional argument for a scene only when it ends in .tscn/.scn/.res/.tres, so a .gpx reaches `OS.GetCmdlineArgs()` untouched (`GpxOpenWith.FromArgs`). An exported build registers itself at every launch (`GpxOpenWith.Register`, so the entry follows the executable when it moves or updates):
  - **Windows:** `HKCU\Software\Classes\UnitSportSwitzerland.gpx` (open command, icon), `.gpx\OpenWithProgids` and `Applications\<exe>\SupportedTypes`. The game is in "Open with", **never the default app**.
  - **Linux:** `~/.local/share/applications/unitsport-switzerland-gpx.desktop` (`MimeType=application/gpx+xml`, `NoDisplay=true`), then `update-desktop-database` where it exists.
  - **macOS:** not done (Godot's macOS export has no document types).
  - A second launch while the game runs opens a second game: there is no single-instance handoff.
- **Android:** an exported `<activity-alias android:name=".GpxOpener">` onto `GodotApp`, added by the editor plugin `addons/unitsport_android` (`_get_android_manifest_application_element_contents`). Not inside GodotApp itself: Godot exports that activity as `android:exported="false"`, where no other app may send it anything. Three filters: VIEW by MIME type (`application/gpx+xml`, `application/gpx`), VIEW by `.gpx` path pattern (providers that call it octet-stream), and SEND ("Share to UnitSport"). `AndroidBridge.OpenedFile` reads the intent through `AndroidRuntime` (`getActivity().getIntent()`: `getData()` for VIEW, the `EXTRA_STREAM` extra for SEND) and rewrites its action, so each intent opens once. It is checked at start and on `NotificationApplicationResumed` (an "Open with" while the game runs).
- **The Android export is a Gradle build** for this: the prebuilt template only takes permissions and features into its binary manifest, never an export plugin's manifest additions.
  - `gradle_build/use_gradle_build=true` in `tools/ci/export_presets.cfg`, in `release.sh`'s `ensure_preset`, and forced by `release.sh` on an older local preset.
  - The build template (`android/`, gitignored) is installed fresh at each export (`--install-android-build-template`).
  - Needs Android platform 36 and build-tools 36.1.0 (Godot 4.7.2's `config.gradle`); Gradle 8.11.1 downloads itself.
  - Measured locally: the first export took ~7 min, a .NET publish and Gradle included.
  - **`-Dorg.gradle.daemon=false` (`GRADLE_OPTS`, `release.sh`):** the daemon inherits the export's output handles, and Godot's console wrapper waited on it for hours after the APK was written.
