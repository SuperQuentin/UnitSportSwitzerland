# Assets: Git LFS, the licence table, import settings, regenerating

- **Where:** `assets/<style>/...`, imported by Godot (no `.gdignore`). Every file or set has a row
  in `assets/ASSETS.md` (source, licence, URL). CC0, MIT-style and Swiss OGD only so far.
- **Git LFS** (`.gitattributes`: jpg, png, glb, exr under `assets/`). A checkout without LFS gets
  small text pointers: the textures fail to load and the realistic styles look wrong, nothing
  else breaks. `git lfs install` once, `git lfs pull` to fix a checkout. Worktrees share the LFS
  store of the main repository.
- **Texture import:** VRAM compressed, mipmaps on, normal maps flagged (`compress/normal_map=1`),
  `detect_3d/compress_to=0`. A headless `--import` writes the defaults (lossless, no mipmaps)
  and never runs the editor's "detect 3D", so the `.import` files are edited by hand and
  committed; the sampler hints (`source_color`, `hint_normal`) do the rest.
- **Trees:** `tools/trees` (`npm install`, `node generate.mjs`) regenerates the `.glb` files and
  copies their textures; then run the game windowed with `--bake-impostors` to re-picture them
  (a headless run renders nothing), and import again.
- **Models** come through `Styles/ModelCatalog` by id, per style, down the fallback chain; the
  procedural builder is the last resort. A model is fitted to the game's canonical size (the
  unit tree; a car's catalogue dimensions), never the other way round: gameplay never reads it.
