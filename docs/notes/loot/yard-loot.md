# Loot in a building site's yard (#627)

A building site's skips and materials are loot containers standing outdoors, in no interior. The
site office's loot is interior loot (#822: the office is the site building's interior).

## Identity: a furniture index from 1000

- `Terrain/Construction/SiteLoot` (pure, tier 0) lists a site's containers from its dressing:
  `SiteDressings.Plan` records a `SiteStockSpot` (slot, `SiteStockKind`, box in the site frame) for
  every skip and every piece of the materials. `SiteLoot.Of` places them in LV95 (`YardStock`).
- A container is named like furniture: **the site's building key (`E_N_I`) and index
  `SiteLoot.FirstYardIndex` (1000) + slot**. Slots: the materials' row `0, 1, 2…` (the same number
  as a liftable pallet's `SitePalletSpot.Slot`, `<building>:c<slot>`), the rebar bundle 100, the
  skips 200 + k. The office's furniture (#822) stays below 1000.
- So `LootService` keeps everything it had: the epoch (`LootTables.Epoch(key)`, the office and its
  yard restock together), the seed (`RngFor(key, index, epoch)`), the masks in
  `user://loot/E_N.json`, the `RequestContents` / `RequestTake` / `Granted` / `Taken` RPCs. Only
  the lookup and the server's check branch on `SiteLoot.IsYard(index)`.

## Server

- `SitePlans.YardAt(source, building)`: the site's containers from the tile's own files (buildings,
  roads, ground), worked on a worker and cached per building (`_siteYards`). Nothing the client
  sends says where a container is or what it is.
- **The check** (`AtYard`): the peer is in no interior (`InteriorManager.SpaceOf` empty) and its body
  is within `SearchReach` (1.3 m) + `ServerSlack` (2.5 m) of the container's edge, within 4 m of
  its height (`SiteLoot.InServerReach`), as `BrCrates.RequestTake` checks the body.
- A refused take is answered with the current contents (as a stale one is), so the panel does not
  hang. The contents are no secret: anyone can roll them from the seed.
- `Taken` goes to the other peers **outdoors within 60 m** of the container (an interior's goes to
  `SpaceOf == key`).
- **A site pallet a machine has moved holds nothing** (`LootService.Moved(YardStock)`:
  `PalletService.IsTaken("<building>:c<slot>")`), as a hall's (`vehicles/pallets`, Loot). A pallet is
  both forkliftable and a container. A narrow pallet drawn in the mesh (no deck fits) is only a
  container.
