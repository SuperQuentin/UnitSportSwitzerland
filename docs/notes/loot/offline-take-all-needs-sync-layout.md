# Offline "take all" needs `GetOrCreate` to answer synchronously

- **Offline "take all" needs `InteriorManager.GetOrCreate` to answer synchronously on a known
  plan.** `LootService.TakeAll` calls `Take` in a loop. Offline, each `Take` runs `ServeTake`
  directly, and the next `Take` bails while `_waiting` is set. It only works if
  `LayoutFor` → `GetOrCreate` finishes before `ServeTake` returns. When `GetOrCreate` first
  awaited a door-to-plan lookup on a worker, only the first stack was taken, and
  `--interiorcheck` failed "take all empties it". Known doors are now answered from
  `_planKeys` + `_cache` with `Task.FromResult`. Keep any new async step behind that fast path.
