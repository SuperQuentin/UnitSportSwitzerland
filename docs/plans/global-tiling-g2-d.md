# G2 D: the flip to `--frame earth` and the LV95 runtime deleted

The detailed plan for step D of `docs/plans/global-tiling-g2.md` (#1500), issue #1515. D makes `--frame earth` the
default and deletes the flat LV95 runtime. The end state, agreed with the user on 2026-11-04: **nothing in LV95
format**. No LV95 tile, key, record or position in the game, the wire, saves or the build's intermediate files. LV95
survives only as notation: how swisstopo sources are read, and how a person types or reads a Swiss coordinate.

Status: **planned** (2026-11-10, from a survey of `main` at `862ddb3e`). Nothing built. D starts once C6 and C7 are
done, plus the three gaps this survey found (G1-G3 below).

## In short

- **D is six PRs (D0-D5), not one** (section 4). The bar compares earth against flat, so it has to be measured while flat
  still exists. The flip is the small, reversible PR; the deletion is the large one, and it lands after the flip has
  run for a while.
- **Three gaps block the flip** (they're not in C7's list yet, filed as #1682-#1684):
  - **G1** (#1682): the earth server builds no generated fill or generated world.
  - **G2** (#1683): a fixture course played online stays flat on the client and the server. 72 of the 90 `*netcheck.sh`
    scripts play on one.
  - **G3** (#1684): the earth server keeps its dormant fleets, steamer, airports, herds and slopes on the flat streamer.
- **The cube build still reads the LV95 build's output**: buildings `.bldg`, `places.json`, region files, the test
  region. MapSetup's cube layer runs the LV95 layers first. The tools must be made independent of LV95 before the
  LV95 build can be deleted.
- **A protocol bump is needed (96)**: RPCs carry LV95 tile ints (farm fields, fog, the flat tile request), tile keys
  inside cow ids, and `BuildingKey` text (about 60 RPC sites).
- **The ratchet can't reach 0 and be retired.** About 4,000 `.E`/`.N` reads are authored LV95 catalogues (festivals,
  adventure, BR, the trailer) and the generator's LV95 source. D turns the ratchet into a **fence**: LV95 only in
  the notation and source files it lists, and 0 everywhere else.
- **The bar needs three probes that don't exist yet**: a re-anchor pop probe, the Geneva → Val Müstair drive, and the
  Geneva → Brest flight. It also needs `TEST_FRAME=earth` in `tools/test.sh`. The data is all on this machine's D:.
  Nothing in G2's bar needs the NAS.

## 6. Risks and rollback

- **Players' saves**: migrations run once with no backup. Mitigations:
  - Unit tests from real old files for every store in section 2, as A2 did.
  - The new paths keep the flat files intact until D3.
  - D3 deletes the old files only once their migration has run (a marker per store).
- **A wrong drop**: dropping loot masks, shop counts, farm cells and contracts loses a few days' state. That's accepted; it's listed in the release notes.
  - Pinball high scores are the one dropped store a player might mind. If the user objects, D2 can convert them through the leaf buildings' `BuildingId` at the old key's tile centre plus the building index, while LV95 tiles still exist on the server.
- **Shipping**: after D3 a fresh install has no terrain unless the release ships leaves (#1650) or a server streams them (#1662). D3 doesn't merge before #1650.
- **The net tier on fixtures**: until G2 lands, `--frame earth` online on a fixture is silently flat. A green earth net tier would then prove nothing. D0's dry run asserts the frame in each net check's log.
- **Performance**: an earth client is measured against flat (`--perfcheck` on the D: region, phone build too), because flat's ring policy and `HorizonLayer` were tuned for years. To record in D2.
- **Parallel LV95 work**: PRs still open against the LV95 build: #1422 (whole Swiss map v3), #1420 (grading), #1540 (builder performance), #1562/#1567 (water stage memory, SIMD), #1565, #1575.
  - D4 makes them moot or forces a port. Comment on each before D4.
  - #1666 (whole lines) changes RoadGen on purpose; it lands before D1.
- **Rollback**:
  - D2: set the default back (a one-line revert) and bump nothing else. The new-path stores stay and are read again on the next flip.
  - D3 and later: git revert only. Hence D3 waits for a playtest and a full tier after D2.
  - D4 and D5 change no behaviour.
